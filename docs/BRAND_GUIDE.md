# Mini-guide de marque KOMYA

Nom : KOMYA. Signature : Connecter · Partager · Développer.

Bleu nuit #071B49 : confiance et structure. Bleu réseau #0B4AA2 : technologie et action. Turquoise #18B6C9 : échange. Vert #20B66A : progression. Orange #FF8A00 : opportunité et accent. Fond #F4F7FC. Texte #142344.

Le bleu nuit domine. Le bleu réseau sert aux actions principales. Turquoise et vert sont des accents. Orange est utilisé avec parcimonie. Employer le symbole validé par le propriétaire sans le redessiner. Icône seule pour l'application ; symbole + KOMYA pour les supports de marque.
